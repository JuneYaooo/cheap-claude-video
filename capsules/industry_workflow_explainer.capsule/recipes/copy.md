# 先取得可用的内容

有参考视频时先取得并核对口播转录，再提炼它的行文逻辑。未取得转录不能声称已按参考稿改写。参考结构与本期事实分别记录：参考贡献叙述方法，本期资料决定工作细节与结论。

将输入中的岗位、旧做法、材料、工具能力、产物和复用方式连成工作链。关键事实缺失时提出具体问题；草稿可标待补，交付稿不把猜测当事实。只确认必要缺口，不让用户重新讲已有材料中的信息。

# 第一轮：交给文案作者的提示词

```text
请为 {industry} 的 {role} 写一条自然口播，听众是 {audience}。
本期只讲 {task}，目标产物是 {outcome}。
旧工作过程：{old_workflow}
实际可用材料：{materials}
当前工作约束：{work_constraints}
工具及已核实能力：{tool_name} / {tool_capabilities}
人员判断与定稿责任：{review_boundary}
下次复用方法：{reuse_method}
参考稿及提炼后的叙述逻辑：{reference}
需逐字保留的开头（若有）：{approved_opening}
期望时长（若有）：{target_duration}

沿着岗位共同感受、旧做法的具体麻烦、给足背景、整理依据、结合条件判断、产物、人工修改、下次复用展开。
每一步交代动作、结果，以及为什么接着做下一步。写成同事把一件工作讲明白的口气，不逐项报功能。
不虚构自己的经历，不补编数据或效率承诺，不把工具输出说成已核实事实。
先给完整口播；字数、估计时长、事实待补项放在口播之外。
```

# 第二轮：让原作者自己编辑

用户指定作者模型时，把初稿、已确认开头和下面的编辑要求交回同一作者。调用失败需如实说明，不把其他模型的改写冒充该作者输出。文案模型可替换，配方不绑定渠道或账号。

```text
请重新读你写的整篇稿，先检查工作逻辑，再编辑表达。
保留已经确认的开头、事实、必要细节和自然的语气。不要为了“去 AI 味”把整篇重新写成另一种腔调。
删除没有增加信息的背景铺垫、宣传形容词、抽象收益、机械排比和段尾升华。
把空话改成谁在做什么、依据什么、得到什么。保留必要限定，长短句随意思变化。
不要靠堆“说真的”“你敢信”等语气词伪装口语，不故意制造语病，也不增加虚构体验。
每一步都要说清为什么需要下一步；保留一次具体的人工判断或修改。
遮住画面顺读全文，确认只听也能明白任务、操作和结果。
只提交修订口播；另附必要的事实缺口，不输出审稿术语或自我评分。
```

# 编辑判断

复审不是关键词查杀。不机械删除所有转折、序号或专业词；有助于理解就保留。作者自改后仍需实际顺读和事实核查，模型的“自然度评分”不能代替编辑判断。

收益落在“少翻哪些材料、少重复哪段整理、哪些经验能下次接着用”。没有测量，不写节省时数或倍数。涉及专业内容时说明人在哪里核查，不额外插入与任务无关的训诫。

标题用岗位、任务或具体成果组织，避免通用风口口号。字幕按自然语义分成短句，口播和字幕一致。以白字深色描边放在稳定的下方安全区，长句自然换行，不逐字跳动。重点词放在画面中的对应对象旁，不用整句彩色字幕争抢注意力。标题、标注与下方字幕避免重复铺满。
