# 以当前讲述选择画面

人物用于建立岗位语境、解释判断和收尾；实际操作用真实录屏；成果说明展示输出中的对应局部。可按用户选择衔接工具实操口播配方的人物、场景和音色，但本包不携带人物身份或固定素材。

真实界面应能看清输入、关键操作、结果与修改。素材不足时补录；示意图须按示意图使用，不能伪装成软件已经完成的动作。可使用明确的虚构演示数据，不把它包装为真实业务成效。

# 视觉参考与信息层级

默认采用 `tool_demo_presenter` 的呈现语法：全屏人物、真实操作大画面、浅色结果卡、重点词贴片与配对对照。适配当前画幅后重新排版，不直接裁切横屏成片。需要人物小窗时，只使用对应语段的真实口型素材。

视觉基底采用低饱和紫蓝到青绿的浅渐变，奶油白内容卡配深绿文字和黄绿细边。标题用黄绿粗体与深色短投影，口播字幕用白字深色描边。正文、标题、标注各司其职；不把每句口播再做成大标题，也不把字幕装进厚重的固定黑框。背景保持稳定，变化落在当前讲解对象上。

# 过程配图按工作关系选择

- 多份材料：文件卡依次出现，再连到共同任务，显示材料怎样汇合。
- 日期与资源：日历或时间轴，把不可用节点与可安排时间区分开。
- 原始问题到决策：问题、条件、产物之间建立有方向的关联。
- 修改：保留同一内容与观察范围，前后并置或上下配对，只突出真正变化的位置。
- 实操与成果：真实界面大幅展示，按旁白裁到相关局部；关键词标注贴近对应对象。

不要让整片都使用“标题加相同列表卡”。图形说明结构，实际界面证明执行；二者不能冒充彼此。

先用人物、操作、配图、对照四类样帧核查标题、字幕和主体的关系，再批量合成。关键原文应在手机尺寸仍能读清；超长内容拆分或选局部，不单纯缩小字体。
