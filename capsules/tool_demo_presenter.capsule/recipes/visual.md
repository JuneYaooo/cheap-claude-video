# 口播、实操与卡片

可复用构图：全屏人物说明任务与结论；大幅真实录屏展示关键操作；圆形人物小窗串联说明；结果卡展示前后对照与成品。保留统一的人物、主色、字体和卡片边框。

操作区是实操段的视觉主角。裁掉无关导航、账号与私人上下文，让输入、控制项、输出可读。关键词贴近对应对象，不能遮住执行结果。

用自己制作或已获授权的素材替换对标案例，保留画面在叙事中的作用。提示词可作为独立排版卡，但不能伪装成实际软件生成记录。代码与页面截图应来自真实文件和实际运行。

片头、角色卡、前后对照、导出成品都须围绕同一任务。视觉变化应提供信息，不靠持续缩放或无意义飞入维持热闹。
