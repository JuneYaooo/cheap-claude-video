# 动效服务解释

沿用卡片弹入、关键词强调、全屏与人物小窗切换等已有形式。每次动画必须对应新信息、操作变化或结果比较。

前后对照使用同一动作和相同观察窗口，标示发生改变的参数。保留足够稳定画面，让观众真正看出修改效果。

真实录屏可按语义剪去等待，保留输入、触发和结果关系。字幕与音效跟随新稿语义时间点，不从参考片机械复制绝对时间戳。
