先让观众选，再解释条件。每段仅一个概率结论，必要条件随首次结论出现。

当期的主题、数字、图表数据、字幕与来源放在输入 JSON；模板只保留结构与样式。

生成前写出至少 3 个 hook variants，选定一个用于真实 first 3 seconds（0–3 秒），并列出 first 20 seconds 的信息推进。输出当期选题角度、封面、标题、脚本大纲与风险边界。

V2 的真实 first 3 seconds 必须出现可作答的二选一，first 20 seconds 内进入规则或首个可检验情形。至少 3 个 hook variants 与选定原因保留在本期 JSON 中。理论概率、穷举计数、随机抽样和实测统计四者必须用准确措辞区分。
