以同一人物和道具连续讲清一个学习动作：日常困境 → 现场任务 → 撤去提示 → 给回忆留出时间 → 核对 → 把方法迁移到真实材料 → 交代证据边界 → 今日行动。

至少一幕出现学习者、桌面、书本或练习工具。任务不是装饰：提示必须真实消失，答案只能在回忆时间结束后重现。抽象研究结论用时间或场景条件承载，不用无来源的数字图表。

每期选择一个可实践的方法，保持人物、书本和笔的造型一致。不要把几个泛泛技巧堆进一条视频。所有知识结论、场景文案、阅读时长、问题列表和来源均属于当期输入。
