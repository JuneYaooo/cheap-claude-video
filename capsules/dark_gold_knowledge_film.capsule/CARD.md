# 黑金知识动画

用代码把一个抽象问题演成可读的图形变化：现实中的异常 → 机制解释 → 前提与边界 → 可操作的结论。深色背景、金色宋体与细线构成栏目识别，具体图表由当期机制决定。

这是由 Agent 按配方编写当期渲染脚本的 preset。随包提供通用绘图、时间线和配乐工具；它们不自动把任意题目变成正确的科普脚本。

适合知识原理、概率、系统与认知类解释。实拍取证、真人表演与照片级画面不适用。

按 capsule.yaml 的 read_order 加载对应阶段；先读输入与内容边界，再做分镜、代码动画、连续样片和交付检查。
